# Landing Page

Landing page estatica do LotoAnalytics.

## Arquivos

- `index.html`: estrutura da pagina.
- `styles.css`: estilos da landing.
- `app.js`: gerador demonstrativo e interacoes.
- `assets/`: imagens e recursos visuais.
- `tests/`: contrato basico da landing.
- `PRODUCT.md`: contexto de produto da landing.
- `DESIGN.md`: direcao visual da landing.

## Como validar

Execute a partir da pasta `LotoAnalytics/apps/landing`:

```bash
node tests/landing.test.js
```

## Papel no produto

Esta landing fica separada do futuro `apps/web`. Ela pode continuar como site publico de conversao enquanto o app autenticado evolui em outro subprojeto.
