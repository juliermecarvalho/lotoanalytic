# Regras De Design - LotoAnalytics Web

## Principios

- Interface operacional, densa e legivel.
- Estados de carregamento, vazio, erro e sucesso devem ser explicitos.
- Formularios devem usar validacao clara e mensagens em PT-BR.
- Tabelas devem priorizar comparacao e leitura rapida.

## Tokens

- Cores, espacamentos e tipografia serao definidos quando o design system for configurado.
